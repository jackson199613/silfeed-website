## How to Modify

### Local Development
1. Clone the repository
2. Edit HTML, CSS, or JavaScript files
3. Test locally by opening `index.html` in browser
4. Commit changes to git

### Deployment
- Push to `main` branch → Netlify automatically deploys
- Changes appear on silfeed.com within seconds

### Common Changes
- **Homepage content**: Edit `index.html`
- **Styling**: Edit `css/main.css`
- **Product pages**: Edit `products/index.html`
- **Blog posts**: Add new files in `blog/` folder
